# Brand & design system

Primary brand color: **`#1B2F5B`** (UCT navy).

Sidebar surfaces: `#0F1A32` / `#0B1324`.

## Typography

System sans stack (Instrument Sans in starter kit). Body `text-sm`, headings `text-lg`–`text-xl`, dashboard KPIs `text-2xl+`.

## Layout

- Staff: sidebar (`primary-800` background, white text)
- Student: top nav, fewer items
- Fee gate: dedicated locked screen — no sidebar

## Components

shadcn/ui — buttons, cards, DataTable (Phase 1 CRUD), forms with `react-hook-form`.

Icons: Lucide only.
